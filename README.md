# ⚡ تولید کانفیگ AmneziaWG 3.0

ابزاری ساده و تحت وب برای تولید کانفیگ‌های AmneziaWG با استفاده از آی‌پی‌های تمیز کلودفلر و پشتیبانی کامل از نسخه 3.0.

## ✨ قابلیت‌ها

- 🔍 **آی‌پی‌های تمیز**: دریافت خودکار لیست آی‌پی‌های کلودفلر (قابل تنظیم دستی)
- ⚡ **پشتیبانی از AWG 3.0**: تولید خودکار پارامترهای جدید شامل:
  - `HeaderProtectionKey` (کلید ۳۲ بایتی تصادفی)
  - `ContentPaddingAddition` (پدینگ پویا با محدوده قابل تنظیم)
  - تایمرهای تصادفی (`KeepaliveTimeout`, `RekeyAfterTime`, و غیره)
- 🎨 **رابط کاربری ساده**: تنظیمات بصری برای کاربران غیرمتخصص
- 📋 **خروجی آماده**: امکان کپی یا دانلود فایل `.conf`

## 🚀 نحوه استفاده

1. فایل `index.html` را در مرورگر خود باز کنید.
2. یک آی‌پی تمیز از لیست انتخاب کنید یا به‌صورت دستی وارد کنید.
3. تنظیمات پدینگ و تایمرها را به دلخواه تغییر دهید (مقادیر پیش‌فرض بهینه هستند).
4. روی دکمه **"ساخت کانفیگ"** کلیک کنید.
5. کانفیگ تولید شده را کپی کرده یا به‌صورت فایل دانلود کنید.
6. در کلاینت AmneziaWG خود، کانفیگ را import کنید.

## ⚠️ نکات مهم

- **HeaderProtectionKey**: این کلید باید بین سرور و تمام کلاینت‌ها یکسان باشد.
- **مقادیر S3 و S4**: در AWG 3.0 باید حداقل ۱۲ باشند.
- **سازگاری کلاینت**: مطمئن شوید کلاینت شما از AWG 3.0 پشتیبانی می‌کند.
